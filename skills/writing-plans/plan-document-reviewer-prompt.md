# Plan Review

Provide the plan, canonical requirements, and relevant code context.

Ask whether the tasks cover the requested outcome, dependencies are ordered,
important contracts are grounded in the code, and acceptance checks can detect
failure. Flag unnecessary work as well as missing work.

Do not require full implementation code, invented signatures, a fixed task size,
or repeated requirements in every task. Report only gaps that would plausibly
misdirect or block the executor.
