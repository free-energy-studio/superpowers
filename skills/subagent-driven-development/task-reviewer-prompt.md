# Task Review

Use the shared review prompt in `../requesting-code-review/code-reviewer.md`,
scoped to this task's requirements and diff.

Give the reviewer the integration context needed to assess its contracts.
The review should catch missing behavior, incorrect assumptions, extra scope,
and avoidable complexity. A plan can be wrong; flag concrete defects even when
the implementation follows it.

Report findings directly. There is no required praise section, verdict table,
or second reviewer for the same small change.
