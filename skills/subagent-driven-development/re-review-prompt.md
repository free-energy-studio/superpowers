# Review a Correction

Give the reviewer the original findings, fix diff, relevant requirements, and
updated verification evidence.

Ask them to check whether each substantive finding is addressed and whether the
correction introduces a new defect. Inspect surrounding code when the fix changes
a shared contract. Do not repeat unrelated review merely to complete another round.

Return remaining findings with evidence, or state that the corrections address
them. A newly discovered serious issue still matters; do not suppress it solely
because it falls outside the original findings.
